# 现状与路线

本文记录当前能做到什么、明确不做哪些事，以及下一步的优先级。凡是未列入"已完成"的能力，都按"未实现"对待。

## 1. 支持范围

| 维度 | 现状 |
|---|---|
| 游戏 | `com.and.games505.Terraria` 的 `1.4.5` 系列（开发基线 `1.4.5.8.6`，Unity 2021.3.56f2） |
| ABI | `arm64-v8a` |
| 设备 | Android 8+，实测 Android 17（小米 2509FPN0BC） |
| 权限 | 不需要 root；不修改游戏 APK；不重签 |
| 不支持 | Google Play 的 PairIP 构建、中文版 `com.xd.terraria`、32 位 |

## 2. 已完成

| 模块 | 状态 |
|---|---|
| 宿主链路（dex 注入、运行时装载、assets 挂载、UnityPlayer 生命周期） | 跑通，APK 不含游戏二进制 |
| 运行时导入（解包、sha256 清单、版本门禁、PairIP 拒绝） | 跑通 |
| 内核（`il2cpp_*` 绑定、引用校验、ShadowHook detour、CoreCLR、ImGui） | 跑通 |
| 托管层（CoreCLR 入口、Mod 发现与依赖排序、内容框架） | 跑通 |
| 内容管线 | 物品、弹幕、NPC、Buff、坐骑、前缀、稀有度、配方、方块、墙壁、玩家与世界生命周期（含侧车存档）、网络包与实体附加数据、城镇 NPC 与商店、音乐与音效、配置、工具提示与触屏按钮 |

## 4. 已知限制

1. **构建依赖三类不可分发文件**：`refs/`、`runtime/`、`interop/generated/`，作者需自备（见 [构建](build.md)）。
2. **版本强绑定**：换游戏版本要整组重做导入与生成，框架不承诺跨版本兼容。
3. **PairIP 构建无法运行**：拒绝而非绕过（见 [运行时导入](runtime-import.md) 第 5 节）。
4. **受限环境（无 root）下的注入路径不可用**：本项目只走"自己的进程里跑游戏"这一条路，不做外部注入。
5. **Android 后续版本的风险**：从可写目录 `dlopen` 与隐藏 API `addAssetPath` 都有收紧趋势，当前目标设备实测可用。

## 5. 优先级

1. release 变体与签名（决定能否对外发布）
2. Tile 绘制 pass 与地图颜色（内容表达力缺口最大）
3. 战斗命中 / 受伤管线
4. 启动耗时的继续压缩（当前瓶颈在游戏线程等待，不在框架）
5. 文档与示例补全

## 6. 明确不做

- 不提供、不代下、不分发任何游戏文件与由游戏派生的代理程序集。
- 不绕过购买、许可或完整性校验（包括 PairIP）。
- 不做 Mod 市场、在线更新与依赖解析；启动器只负责导入、启停、删除。
- 不引入第二套 hook 框架（Harmony / MonoMod / 自建 detour）。
